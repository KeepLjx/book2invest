# 个人养老金投资指南（知识体系）

本技能封装了《个人养老金投资指南》（银行螺丝钉著）的完整方法论，用于指导普通投资者利用个人养老金账户进行养老规划与投资。核心理念：**提前规划第三支柱，用足个税递延优惠，好品种+好价格+长期持有，退休后按4%法则取用**。

## 核心原则（始终遵守）

1. **只靠社保不够**：现收现付制下，城镇职工养老金平均替代率已从2000年71.5%降至2022年37.9%，远低于70%的舒适线，且老龄化加剧还会继续走低；大多数人没有第二支柱（企业/职业年金），养老补充主要靠第三支柱。
2. **税优是参加的首要理由**：存入即享税前扣除（每年上限12000元）、投资收益暂不征税、退休领取时仅按3%缴税。当前边际税率越高越划算（参考：月入6000以下不适合，7000~10000吸引力不大，15000以上较划算）。
3. **封闭运行是双刃剑**：资金通常退休后才能取（丧失劳动能力/出国定居/患重大疾病/失业等可申请提前领取），强制长期投资，专治"拿不住"。
4. **五大类品种无优劣**：储蓄存款、国债、保险、理财、公募基金，按风险承受能力自低向高匹配；含股票仓位的品种必须在4~5星级低估阶段投入。
5. **账户内外互补**：每年12000元额度不够用；账户外资金按"100-年龄"配置（70岁后股票不低于30%），新增收入约20%用于定投。

## 快速决策框架（无需加载参考文件即可回答的要点）

**个税递延速算**：每年节税 ≈ 存入金额 ×（当前边际税率 - 3%），外加递延期间的投资增值差异。例：税率10%每年存12000元约省1200元；税率20%约省2400元。

**五大类品种速览**：存款（1.5%~2%，保本）→ 国债（略高，几乎无违约风险）→ 保险（锁定利率，现金价值写入合同）→ 理财（R2为主，基准3%~6.25%，封闭1~5年）→ 公募基金（养老FOF省心/指数基金透明低费，波动最大长期收益最高）。

**6步投资法**：① 按边际税率判断适不适合参加 → ② 算退休时间 → ③ 选策略（新手选目标日期FOF，退休年份夹在两档间选远的；有经验选指数基金，经典搭配：沪深300+中证500 或 A500+红利）→ ④ 挑产品（FOF看费率/公司实力/夏普比率/分散配置；指数基金看费率/规模/追踪误差）→ ⑤ 4~5星级低估买入，定期不定额越低估买越多 → ⑥ 退休后每年取用不超过4%。

## 交互要点

- 用户问"要不要开通"时，先问清：月收入/应纳税所得额（估算边际税率）、年龄与预计退休时间、资金是否长期不用。
- 用户要做投资方案时，先问清：投资经验与风险承受能力、距退休年限（5年以内建议选波动小的养老理财/储蓄）、是否接受基金波动。
- 涉及当前可投产品名单、当前螺丝钉星级/估值时，提示需查询最新数据（书中名单截至2025年3~4月：基金289只、存款466款、保险211款、理财33款），不臆造实时信息。
- 书中阈值（替代率70%/55%、月收入分档、4%法则等）引用时说明其逻辑与适用条件，提示结合个人实际校准。
- 所有建议落到"要不要开、存多少、买什么、何时买、怎么取"五个问题上。
