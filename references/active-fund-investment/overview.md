# 主动基金投资指南（知识体系）

本技能封装了《主动基金投资指南》（银行螺丝钉著）的完整投资方法论，用于指导普通投资者挑选主动基金、构建基金组合并长期持有。核心公式：**好品种 + 好价格 + 长期持有 = 好收益**。

## 核心原则（始终遵守）

1. **买主动基金就是买基金经理**：主动基金依靠基金经理选股，基金经理的投资能力和风格稳定性是核心；基金经理离职是最大风险，需用基金经理池对冲。
2. **好品种+好价格+长期持有=好收益**：再好的品种买贵了也会亏钱；再便宜的阶段也不代表马上上涨。先挑好品种，等到4~5星级便宜阶段买入，耐心持有到3星级以上收获。
3. **股票基金长期年化约14%**：A股股票基金长期平均年化收益率约14%（中证全指约10%，优秀基金经理可达15%以上），债券基金约6%，货币基金约2%~3%。但个人投资者平均年化仅约2%，差距源于追涨杀跌和频繁交易。
4. **用3~5年不用的闲钱投资**：股票基金可能出现50%以上的短期波动，低估买入后短期仍可能下跌10%~20%。
5. **组合投资而非单吊一只**：分散配置不同风格、不同行业的基金经理，用组合降低单个人风险和波动，配合再平衡增厚收益（1+1>2）。
6. **少折腾**：持有时间越长盈利概率越高（持有10年以上盈利比例98.41%）。个人投资者平均持有基金仅3个月、年换手率400%，是亏钱主因。

## 快速决策框架（无需加载参考文件即可回答的要点）

**5种投资风格速览**（判断基金经理风格先看重仓股平均估值与行业偏好）：
- 深度价值（格雷厄姆）：低市盈率、低市净率、高股息率；熊市回撤小，但可能连续两三年跑输大盘
- 成长价值（巴菲特）：高ROE，合理价格买优秀公司长期持有，穿越牛熊
- 均衡（彼得·林奇）：又好又便宜，PEG约1~2；牛市中后期常降仓位，易出长跑冠军
- 成长（费雪）：收入/盈利增速≥15%，估值次要；进攻性强，牛市涨得多熊市跌得狠（回撤可超40%）
- 深度成长：商业模式未验证的早期行业，类似风投；牛市弹性大，熊市可跌70%~80%

**螺丝钉星级（主动基金买卖时机的核心工具）**：
- 5星级：最便宜，投资价值最高（3~5年一遇）
- 4星级：比较便宜（约2年一遇）→ **4~5星级是买入/定投主动基金的阶段**
- 3星级：正常估值 → 停止买入，耐心持有，可考虑部分止盈
- 2星级：偏贵 → 进一步降低股票比例（如降到30%）
- 1星级：泡沫 → 全部止盈

**挑老将三标准**：长期年化收益率≥15% + 至少一轮完整牛熊市的从业时间（约10年）+ 管理过至少20亿元大资金。同时符合者不到1%。

**组合构建5步**：构建基金池 → 分散投资风格 → 分散不同行业 → 4~5星级买得便宜 → 按估值再平衡。

**家庭资产配置**：存量资金按"100-年龄"定股票比例（70岁后不低于30%），4~5星级投入股票基金投顾组合；增量资金每月拿出收入约20%定投，4~5星级投股票组合、1~3星级投债券组合。

## 交互要点

- 用户问"这只主动基金怎么样"时，引导其提供或查询：基金经理姓名与从业年限、长期年化收益率、投资风格、基金规模、股票仓位、前十大重仓股及行业分布、换手率、费率，再逐项对照标准分析。
- 用户问"现在能不能买主动基金"时，提醒需查询当前螺丝钉星级/巴菲特指标/股债性价比等牛熊信号，再对照买卖规则给结论；不臆造实时估值数据。
- 用户纠结选哪只基金时，先确定其要配的投资风格，再从擅长该风格的基金公司中挑选该风格的基金经理，"从擅长成长的里挑成长，从擅长价值的里挑价值"。
- 书中数据（14%长期年化、星级出现频率、行业收益对比等）基于成书时（2022年）的统计，引用时说明数据背景与逻辑来源，并提示用户按当前环境校准。
- 所有建议落到"买什么、怎么买、何时买、何时卖"四个问题上；不做个股推荐，不预测短期涨跌。
