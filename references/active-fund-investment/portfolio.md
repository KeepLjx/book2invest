# 构建主动基金投资组合

> 适用场景：构建主动基金组合、分散配置、再平衡策略、组合5步法。核心结论：用组合方式投资一篮子主动基金，比单投一位基金经理更稳妥。

## 1. 为什么要做组合投资

组合投资三大优势：

1. **减少基金经理的个人风险**：基金经理可能跳槽、转私募、退休。构建基金经理池储备一批优秀经理，一人离职可从池中找同类顶上，投资不中断（如球队精选球员上场，受伤有替补）。
2. **降低波动风险**：A股有风格轮动（价值/成长轮动、大盘/小盘轮动），分散配置不同风格、不同行业，组合波动更小，持有体验更好，更容易坚持长期投资。
3. **提供更多收益来源**，四层递进：
   - 股票市场整体收益（中证全指长期年化约10%）
   - 股票基金选股超额（股票基金总指数长期年化约14%，高约3~4个百分点）
   - 精选优秀基金经理（可达15%以上）
   - 组合的分散配置和再平衡技巧（1+1>2）

## 2. 分散配置：利用A股风格轮动

**风格轮动规律**（书中案例）：
- 成长/价值：2015年成长强 → 2016—2018年价值强 → 2019—2020年成长强 → 2021—2022年价值又强。
- 大盘/小盘：2012—2015中小盘强（大盘被称"大烂臭"）→ 2016—2020大盘强 → 2021中小盘又强。
- 大中小盘划分：沪深300（大盘，平均市值几百亿到千亿）、中证500（中盘，100~200亿）、中证1000（小盘，平均几十亿）。
- **长期回报接近**：300价值全收益与300成长全收益从2004年底1000点到2022年5月点数趋于一致。只是短期有强弱。

**操作含义**：未来哪种风格更强无法预测；当前暂时低迷的风格未来几年表现好的概率相对高。分散配置不同风格，哪种强都受益；哪种风格估值更便宜就多配一点，耐心等待其进入强势阶段。

**分散配置的两个前提**：①对象之间涨跌不同步（如不同风格）；②每个对象长期收益都不错。

**回测验证（2016年初—2022年3月）**：单配成长老将收益约70%、最大回撤约37%；单配价值老将收益约85%、回撤约24%；各50%每年再平衡一次——收益约97%、回撤约28%。收益更高，回撤居中。

## 3. 再平衡：获得额外收益

只做分散，市场涨跌会使比例自然偏离，失去分散效果，需要再平衡。

**香农50:50动态平衡示例**：股票不涨不跌（先腰斩再翻倍），50%股票+50%现金每年恢复比例一次，资产仍增加12.5%。

**使用再平衡的两个条件**：①至少两个涨跌不同步的资产；②设定好比例和再平衡规则。

**4种常见再平衡策略**：
1. **定期再平衡**：如50:50每年平衡一次，简单易操作。
2. **偏离度再平衡**：比例偏离到一定程度（如60:40）触发。
3. **估值再平衡**：不看价格看估值，低估的风格提高比例、高估的降低。价格上涨估值不一定上涨。**构建主动基金组合时最常用**。
4. **波动风险再平衡（风险平价）**：按各类资产波动率分配比例，使每类资产对组合的风险贡献相同。较复杂。

## 4. 5步手把手教你构建组合

**步骤1：构建基金池**。按5种风格（深度价值/成长价值/均衡/成长/深度成长）分别筛选优秀老将和"黑马"基金经理放入池中。定期更新，新人涌现及时补充。基金经理离职或出风险时，从池中快速找同类替代。

**步骤2：分散投资风格**。从池中挑选时覆盖多种风格。各风格估值差不多时平均分配；某种风格估值较低时适当提高其比例。

**步骤3：分散不同行业**。同一风格的基金经理行业偏好也不同（如同为深度价值，有的偏好金融地产、有的偏好能源材料），组合涵盖更多行业可进一步降风险。

**步骤4：买得便宜，先保护好自己**。组合构建好后不立即买，等到市场4~5星级便宜阶段再投入，越接近5星级价值越高。买贵了即便买的是优秀基金经理，也可能面对短期较大波动。

**步骤5：按估值再平衡**。持有过程中用估值再平衡：某风格涨多且估值偏高时止盈一部分、增加低估风格比例；该风格再次便宜时再加回。时间拉长可获得超额收益。

**实践提醒**：实战中还有诸多细节（基金经理能力评估、限购、费率、风格是否漂移、调仓置换操作），新手易受市场涨跌影响无法严格执行（如一不小心重仓一两个品种），没时间研究的投资者可考虑基金投顾组合（见advisory-allocation.md）。
