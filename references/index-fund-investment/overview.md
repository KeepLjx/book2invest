# 指数基金投资指南（知识体系）

本技能封装了《指数基金投资指南》（银行螺丝钉著）的完整投资方法论，用于指导普通投资者进行低估值指数基金定投。核心理念：**价格围绕价值上下波动，只在低估时买入、正常估值时持有、高估时卖出**。

## 核心原则（始终遵守）

1. **攒资产而非攒现金**：现金会被通胀侵蚀，要积累能产生现金流的资产。长期看股票类资产收益率最高（国内股票基金长期年化约14%，债券基金6%~7%，货币基金2%~3%），指数基金是普通投资者获取股票收益的最佳工具。
2. **指数基金三大优势**：长生不老（定期新陈代谢吸收新公司）、长期上涨（背后公司盈利增长）、成本低廉（费率在股票基金中最低）。
3. **绝不无脑定投**：指数基金不是任何时候都值得买。低估时定投、正常时持有、高估时卖出，收益可比无脑定投高两倍以上（书中2004~2015回测：无脑定投上证50年化12.3%，改进策略29.27%）。
4. **定投"双核制"**：靠工资等现金流提供"防御资产"，靠低估值指数基金放大收益。手里没资产时重心放在工作上。
5. **3年以上投资周期**：只用3年内不用的闲钱定投，每月定投金额建议不超过月结余的一半（留备用金）。

## 快速决策框架（无需加载参考文件即可回答的要点）

**估值四指标**：市盈率PE（=市值/盈利，要求流通性好、盈利稳定）、盈利收益率（=1/PE，格雷厄姆常用）、市净率PB（适用盈利不稳定/周期性行业）、股息率（=盈利收益率×分红率）。

**盈利收益率法（盈利稳定的指数，最适合新手）**：
- 盈利收益率 > 10%：分批定投买入
- 6.4% ~ 10%：停止买入，坚定持有；资金转投其他低估品种
- < 6.4%（≈国内债券基金长期平均收益）：分批卖出（如分10份每月卖1份）

**博格公式（盈利高速增长或周期性指数）**：
年复合收益率 ≈ 初始股息率 + 投资期内市盈率变化率 + 盈利增长率。应用：股息率高时买入 + 市盈率处于历史低位时买入 + 耐心持有等待均值回归。周期性行业（证券、能源等）用PB变种替代。

**卖出三条件（巴菲特）**：基本面恶化 / 过于昂贵 / 有更好的品种。

## 交互要点

- 用户要做定投计划时，先问清：每月可投资金额、资金可用年限（是否3年以上不用）、投资目的（养老/加薪/教育）、风险承受能力。
- 用户问"现在能不能买"时，提醒需要查询该指数当前的市盈率/盈利收益率/股息率及其历史分位，再对照估值法给结论；不臆造实时估值数据。
- 所有建议落到"买什么、怎么买、卖什么、怎么卖"四个问题上。
- 书中具体阈值（10%、6.4%、100-年龄规则等）基于成书时的利率环境，引用时说明其逻辑来源（如无风险利率、债券基金平均收益），并提示用户按当前环境校准。
